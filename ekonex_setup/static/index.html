EKONEX

Configura l'accesso privato

Primo avvio · GHCR

Questo strumento configura il registro dei pacchetti e installa Ekonex Installer dopo il salvataggio. Non migra, arresta o elimina gli altri add-on. Mantieni attiva la modalità protezione.

Controllo registro…

1. Crea il token

Un token dedicato a questo impianto, con il solo permesso read:packages.

2. Inserisci e verifica

Il token viene inviato soltanto a questo add-on, a GitHub/GHCR per verificarlo e al Supervisor quando confermi il salvataggio. Non viene scritto nei log o nei file dell'add-on. Per accessi remoti usa HTTPS.

3. Salva in e-Control

Apri scheda Ekonex Installer →

0.1.0-test7 · La credenziale è custodita nel registro nativo Supervisor. Nessuna sostituzione automatica.

Crea il token GitHub

  1. Accedi al tuo account GitHub autorizzato ai pacchetti Ekonex.
  2. Apri Generate new token (classic) →

    Settings → Developer settings → Personal access tokens → Tokens (classic).

  3. In Note scrivi il nome dell'impianto. Usa un token diverso per ogni impianto.
  4. Scegli una scadenza e annota quando rinnovarlo.
  5. Spunta soltanto read:packages. Lascia vuoti repo, write:packages, delete:packages e tutti gli altri permessi.
  6. Premi Generate token e copialo: GitHub lo mostra una sola volta.
  7. Torna qui: inserisci l'account che ha creato il token e incolla il token nel campo dedicato. Premi Verifica, poi conferma e Salva.
Non inviarlo in chat, screenshot o URL. Il nome del token non ne limita i pacchetti: contano i permessi dell'account. Puoi revocarlo da GitHub → Tokens (classic); le copie già installate non vengono cancellate.
